# coreui-kit

Copy [CoreUI-Kit](https://core-ui-kit-v2-3.vercel.app) React + Tailwind CSS components straight into your project — no dependency on this package at runtime, just a copy tool.

## Usage

```bash
npx coreui-kit add tabs-panel
npx coreui-kit add tabs-panel premium-wallet-card --install
npx coreui-kit list
```

By default, files are written to `src/components/coreui-kit/`. Use `--path <dir>` to change that, `--overwrite` to replace existing files, and `--install` to automatically install any missing npm dependencies (e.g. `lucide-react`).

Browse the full component list at [core-ui-kit-v2-3.vercel.app](https://core-ui-kit-v2-3.vercel.app).
